# 戰鬥背景

- 尺寸:209×140,PNG,像素風,左右可首尾相接(捲動用)。
- `bg_NN.png`:背景(底)。天空與雲的位置是透明的,後面由程式畫天空特效。
- `fg_NN.png`:前景,疊在人物前面,其餘透明。**同一組編號配同一組背景**(`bg_01` 配 `fg_01`);沒有前景的背景就不用放對應的 fg。
- 目前:`bg_01` + `fg_01`(森林小路)、`bg_02` + `fg_02`(洞窟,282×140)、`bg_03` + `fg_03`(沙漠黃昏,282×140,天空沒有挖空,保留原圖)。

- `sky_mask_03.png`:沙漠的天空範圍(不透明處=天空)。飄動的雲只畫在這個範圍內,所以會躲在金字塔後面;雲不要低於地平線。
- `clouds.json`:雲的形狀(4 朵,取自沙漠原圖)與各主題色盤(day 白雲 / dusk 粉雲)。森林用 day 色盤,沙漠用 dusk 色盤。
- 暫存(只有背景,尚未切前景/調站位,之後逐張修):`bg_04`(熔岩,564×140)、`bg_05`(冰原,564×140)、`bg_06`(墓穴,564×140)、`bg_07`(王座廳,282×140)、`bg_08`(魔王城,564×140)、`bg_09`(城堡大廳,564×140)。
