# 戰鬥特效圖

## 屬性編號（所有特效共用）
檔名後綴代表屬性，例如 `slash_03.png` 是雷電斬擊。

| 後綴 | 屬性 |
|---|---|
| `_00` | 無屬性（普通攻擊、無屬性技能） |
| `_01` | 火焰 |
| `_02` | 冰霜 |
| `_03` | 雷電 |
| `_04` | 疾風 |
| `_05` | 自然 |
| `_06` | 光明 |
| `_07` | 黑暗 |

某個屬性還沒有圖時，程式會改用 `_00`。

## 目前的特效
| 檔案 | 說明 |
|---|---|
| `slash_00`～`07` | 斬擊（劍、斧、vfx=slash）。48×48，縮成 24×24 顯示，中心對準怪物；由上往下劃出約 0.15 秒，再放大 15% 淡出約 0.2 秒。 |
| `arrow_00`～`07` | 飛箭（弓、vfx=arrow）。48×48，縮成 24×24，箭頭朝右、會依飛行方向旋轉；飛行時後方由程式畫出屬性色的尾勁，命中後尾勁約 0.3 秒淡出。原圖左緣被切到的尾端已做淡出處理。 |
| `missile_00`～`07` | 魔法彈（杖、書、vfx=missile）。48×48，原圖朝右上 45 度畫；程式會轉向對齊飛行方向（含拋物線的切線），縮成 24×24，頭部落在彈道上，命中時接程式畫的爆散光點。 |
| `thrust_00`～`07` | 刺擊（匕首、槍、vfx=thrust）。48×48，箭頭朝右；縮成 24 寬（槍 34 寬），80% 不透明；`thrust_07`（黑暗）原圖是斜的，程式另外轉 45 度擺成水平，並把高度壓到 60%；槍尖對準怪物前方，由尾端往前伸出約 0.12 秒，再往前滑一點淡出約 0.22 秒。 |
