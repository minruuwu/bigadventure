# 戰鬥特效圖

## 屬性編號（所有特效共用）
檔名後綴代表屬性，例如 `slash_03.png` 是雷電斬擊。

| 後綴 | 屬性 |
|---|---|
| `_00` | 無屬性（普通攻擊、無屬性技能） |
| `_01` | 火焰 |
| `_02` | 冰霜 |
| `_03` | 雷電 |
| `_04` | 疾風 |
| `_05` | 自然 |
| `_06` | 光明 |
| `_07` | 黑暗 |

某個屬性還沒有圖時，程式會改用 `_00`。

## 屬性粒子（程式畫，不用圖）
所有帶屬性的特效（斬擊、箭、魔彈、刺擊、打擊、拋擲、治療、支援）都會另外加一層粒子：命中時從目標身上散開約 0.5 秒；箭、魔彈、拋擲在飛行途中也會沿路灑一些。

| 屬性 | 粒子 |
|---|---|
| 火焰 | 火星飛散（往外噴、往上飄） |
| 冰霜 | 冰晶（十字小晶體，慢慢飄落） |
| 雷電 | 黃色折線電流，會閃爍 |
| 疾風 | 青綠色的弧形氣流，繞著目標轉 |
| 自然 | 綠色光點往上飄 |
| 光明 | 小十字閃光 |
| 黑暗 | 黑紫色氣焰往上竄 |
| 無屬性魔彈（杖、書） | 藍色光點 |

其他無屬性特效不加粒子。

- `blood_slash.png`：血系斬擊（vfx=blood，吸血類技能）。血紅色新月刀光，48×48，縮成 24×24 顯示；由上往下劃出約 0.15 秒，再放大 15% 淡出，之後噴血珠（程式畫）。
