# 戰鬥特效圖

## 屬性編號（所有特效共用）
檔名後綴代表屬性，例如 `slash_03.png` 是雷電斬擊。

| 後綴 | 屬性 |
|---|---|
| `_00` | 無屬性（普通攻擊、無屬性技能） |
| `_01` | 火焰 |
| `_02` | 冰霜 |
| `_03` | 雷電 |
| `_04` | 疾風 |
| `_05` | 自然 |
| `_06` | 光明 |
| `_07` | 黑暗 |

某個屬性還沒有圖時，程式會改用 `_00`。

## 目前的特效
| 檔案 | 說明 |
|---|---|
| `slash_00`～`07` | 斬擊（劍、斧、vfx=slash）。48×48，縮成 24×24 顯示，中心對準怪物；由上往下劃出約 0.15 秒，再放大 15% 淡出約 0.2 秒。 |
| `arrow_00`～`07` | 飛箭（弓、vfx=arrow）。48×48，縮成 24×24，箭頭朝右、會依飛行方向旋轉；飛行時後方由程式畫出屬性色的尾勁，命中後尾勁約 0.3 秒淡出。原圖左緣被切到的尾端已做淡出處理。 |
