# 戰棋模式規格（2026-10-21 定案，尚未實作）

新對話接手時先讀這份。示意圖：`docs/tactics_mock.png`。

## 定位
- 每一關都可以由玩家選「自動」或「戰棋（手動）」。
- 數值、傷害公式、技能倍率、狀態、反應技、被動、符文、怪物資料、獎勵全部沿用 `battle/engine.js` 與 `assets/data/*.csv`；戰棋只改「站位、移動、選目標、範圍、冷卻」這一層。
- 隊長一個人操控全隊（最多 4 人，含隊友角色）。
- 中途離開／按「自動」：剩下的戰鬥交給自動 AI 打完（我方也用 AI）。
- 目前沒有體力、連戰，不用處理。

## 地圖
- 固定 10×10，沒有地形、障礙。
- 敵人出生在上方中間、我方在下方中間；王左右可以排其他怪。
- 畫面可拖曳、雙指縮放，右上角小地圖（白框 = 目前畫面位置）。

## 回合
- 依速度輪流，一次動一個單位（同現在：速度高先動，同速隨機）。
- 每個單位：先移動再出手；可只移動或只出手；出手後不能再移動。可「取消移動」（出手前）、「待機」。

## 移動（2026-10-21 改：改由資料表決定，不再用速度換算）
- 移動格數 = `move` 欄：玩家看目前裝備職業的 job_attribute.csv `move`，怪物看 monster_info.csv `move`。空白暫定 4。
- 速度只決定出手順序，不影響移動；目前沒有被動／狀態加減移動。
- 距離只算上下左右步數（曼哈頓距離），不能斜走。
- 可穿過友軍，不能穿過敵人；不能停在有人的格子。

## 射程與範圍（2026-10-21 改：改由資料表決定）
新欄位（加在各表最後面，程式用欄位名稱讀）：

| 表 | 欄位 | 說明 |
|---|---|---|
| weapon_info.csv | `range`、`area`、`area_size` | 該武器的普通攻擊 |
| monster_info.csv | `atk_range` | 怪物普攻射程（範圍一律單一格）；取代原本寫死的「法系怪 4」 |
| skill_info.csv | `range`、`area`、`area_size` | 技能；`range` 空白 = 跟施放者的普攻射程一樣（玩家看武器、怪物看 `atk_range`） |

- `range`：能點到多遠（曼哈頓距離）。`0` = 以自己為中心，不用點格子。
- `area` 範圍類型：
  - `single` 單一格：點射程內的一個單位。`area_size` 不用填。
  - `line` 直線：從施放者旁邊那格往上下左右其中一個方向延伸，**長度 = `range`**，`area_size` 不看；**貫穿**，整條線上的目標都打到。點那條線上任一格決定方向。
  - `diamond` 菱形：在射程內點一格當中心，曼哈頓距離 ≤ `area_size` 的格子都算（size 1 = 5 格、size 2 = 13 格，即原本的「九宮格 + 上下左右各 1」）。
- 打敵人還是打隊友照舊看 `target` 欄（enemy_* 打敵人、ally_* 打隊友、self 自己）；自動戰鬥不看這些新欄位。
- 槍的普攻 = `line`、`range` 2：直線 2 格，兩格上的敵人都打到。
- 欄位空白時：`move` → 4；`atk_range` → 1；技能 `range` → 普攻射程，但治療／輔助（ally_*）→ 3；技能 `area` → enemy_all／ally_all／ally_others 當 `diamond` 2，其他當 `single`。
- 2026-10-21 已照舊規則預填：職業、怪物 `move` 全部 4；武器照原本射程（槍 = `2 / line`）；怪物 `atk_range` 1（哥布林巫師、黑暗蛛后 4）；技能：全體技 `3 / diamond / 2`、我方單體 `3 / single`、自身 `0 / single`、玩家單體攻擊 range 空白（= 武器）、怪物單體攻擊照 vfx（無／slash／smash／thrust 1、throw 3、arrow／missile 4）。
- 例：劍 `1 / single`；弓 `3 / single`；書、杖 `4 / single`；槍 `2 / line`；舊規格的全體技 = `3 / diamond / 2`；以自己為中心的戰吼 = `0 / diamond / 2`。
- 多段隨機技（pick = random_each，如黑暗箭）：每一下在範圍內的目標中隨機挑。
- 王佔 3×3：範圍蓋到王好幾格也只算一次。

## 技能與冷卻
- 戰棋中，所有已學會的戰鬥技能都能選（不受 4 格循環限制）。
- 每招冷卻 4 回合（以施放者自己的行動次數計）；普通攻擊無冷卻。按鈕右上顯示「CD n」，冷卻中變暗。
- 反應技、被動、符文照舊自動觸發；反擊類反應技只有在攻擊者位於自己普攻射程內才發動。

## 嘲諷／保護（戰棋專用規則）
- 有嘲諷或保護狀態的單位：2 格內的友軍受到「單體」傷害時改由自己承受。
- 代受傷害用保護者自己的數值重新計算（閃避、減傷、抗性）。
- 範圍技能不觸發保護。
- 多個保護者符合時隨機挑一個。

## 召喚
- 召喚出來的怪出現在召喚者旁邊的空格（沒有空格就不召喚）。

## 王
- 佔 3×3 格，以中心格計算位置與移動。
- 打到任一格都算打到王；範圍技蓋到王好幾格也只算一次傷害。

## 怪物 AI（第一版）
- 能打到就照「可用技能中倍率最高／冷卻好的」打；打不到就走向最近的敵人。
- 範圍技挑能打到最多人的中心格；治療挑生命比例最低者。

## 介面（見示意圖）
- 上方：行動順序列（依速度，金框 = 現在輪到的人）。
- 中間：地圖。藍 = 可移動、紅框 = 普攻射程、淡紅 = 技能射程、橘 = 範圍預覽；王外框紅色虛線 3×3。
- 下方：目前角色（職業圖示、名字、武器、移動力、射程、血條）、技能按鈕（名稱、類型、射程、CD）、取消移動／待機／自動。
- 範圍技：點一格預覽，再點同一格確認施放。
- 正式版角色用紙娃娃（common/doll.js），怪物用現有圖與動畫。
